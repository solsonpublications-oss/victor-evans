THE GENERATIONAL CURSE BREAKER — website source
================================================

This zip contains the full Next.js 16 source for the book website at
thegenerationalcursebreaker.com.

SETUP (5 minutes)
-----------------
1. Unzip this folder.
2. Install Node.js 20+ and either bun (recommended) or npm.
3. From inside the unzipped folder, run:

       bun install            # or: npm install
       bun run db:generate    # or: npx prisma generate
       bun run dev            # or: npm run dev

4. Open http://localhost:3000

-----
